1. ¿Qué color tendrá el texto?
Rojo

2. ¿Qué selector tiene mayor especificidad?
#principal p {
    color: red;
}

3. ¿Qué ocurriría si eliminamos el selector #principal p?
Que pasaría a ser morado

4. ¿Qué sucedería si añadimos otra regla .mensaje.destacado al final?
Se aplicaría la última regla por la cascada del CSS

5. ¿Qué buenas prácticas aplicarías para evitar este tipo de conflictos?
- Utilizar selectores sencillos y evitar demasiados IDs.
- Reutilizar clases para aplicar estilos.
- Evitar repetir reglas CSS innecesariamente.
- Mantener un orden organizado en el archivo CSS.
